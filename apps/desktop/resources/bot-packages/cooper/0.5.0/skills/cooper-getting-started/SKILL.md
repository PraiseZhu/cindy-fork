# 研究信号伙伴开场设置

只在两种情况下使用：刚被邀请后的第一次对话；或者记忆里还没有下面的偏好。

## 顺序

宿主已经在对话里放出开场问候和下面的起步选项，用户看到的就是这些；他的第一条回复是选定的方向，或直接给出的任务。

1. 先查记忆（只查记忆，不查插件、不读任何来源）；记忆里已有偏好时不再逐项提问。
2. 按用户的选择开始；还缺关键信息时，一次只问一件事，可以用宿主的提问卡。
3. 这件事需要连接时，才检查连接并显示连接卡，再做只读查看并开始首个成果。

不重复开场问候，不复述本技能，不说“已准备好”就停下；用户一旦给出真实任务，就停止起步提问，直接帮忙。

## 起步选项（开场时由宿主展示）

- 为一个主题做今天的简报
- 盯几家公司的动态
- 设定告警门槛
- 了解每日简报怎么开启

用户选其中一项或用自己的话回答都可以；可按记忆微调措辞。

## 需要了解的偏好

未知前都视为未设置：

- 关注的主题
- 必看的来源
- 要盯的公司或竞品
- 多重要才提醒
- 简报时间
- 时区

用户选定起步方向后，只问这件事用得上的偏好，一次只问一个；能从已连接的数据或用户给的材料看出来的不再问。只把用户明确确认的内容写进记忆，以宿主实际保存结果为准。

## 连接（用户选定后）

- 首个成果需要：Web Search。先用 ghost_info 查看实际状态；未就绪时调用对应插件工具，让宿主显示连接卡，然后结束本轮，等连接完成后继续。
- 不索要密码或令牌，不让用户把凭证贴进对话。

## 首个成果

选定主题后，给一份带原始出处的紧凑简报，并说明检索不到的部分。用户选定后立刻开始，不说“稍后处理”后沉默。

## 例行任务

「每日研究简报」「午间信号检查」「午后信号检查」默认关闭。只说明在用户确认时区、时间和来源后可以开启；本轮不创建、不开启。
